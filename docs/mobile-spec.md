# 安卓 App（apps/mobile）功能规格

> 状态：第一版已实现。本文档为需求冻结稿，
> 实现时以此为准，有变更先改文档再改代码。

## 技术栈

- Expo + React Native + TypeScript
- EPUB 渲染：WebView 内嵌 epubjs（与 Web 阅读端同一套渲染与进度逻辑）

## 功能需求

### F1 双书源

- **云端书源**：登录服务器后读取书架，在线阅读或手动下载到本地，
  进度同步到服务器。
- **本地书源**：通过系统文件选择器导入设备上的 EPUB / PDF / TXT，
  导入的书籍元数据与阅读进度保存在本地。
- 无服务器配置时 App 完整可用（纯本地模式）；
  配置服务器后出现云端书架，本地书与云端书并列展示。

### F2 权限最小化

- App 运行期间**不申请任何存储权限**。
- 导入图书使用系统文档选择器（SAF，`expo-document-picker`），
  仅获得用户所选文件的临时读取授权。
- 网络访问无需运行时权限；不申请定位、通知、通讯录等任何无关权限。

### F3 设置（仅两项）

| 设置项 | 说明 |
|--------|------|
| 服务器地址 | 如 `https://books.example.com`，留空即纯本地模式 |
| 访问令牌 | 登录成功后由服务端签发的 JWT |

- 已连接时显示状态并提供「断开并使用纯本地模式」。
- 其余偏好（字号、行距等排版设置）属于阅读器内设置，
  存放于本地，不占用本设置页。

### F4 阅读器排版

与 Web 阅读端一致（档位常量同源 @starcloud/shared）：

- 字号：8 档（80% – 180%）
- 行间距：4 档（1.4 / 1.6 / 1.8 / 2.0 倍）
- 左右页边距：4 档（窄 / 中 / 宽 / 很宽）
- 单列 / 双列二选一 —— **待办**：App 暂未实现双列排版（Web 端
  仅视口 >900px 且开启双列时生效），偏好键与 Web 对应持久化
- 所有设置持久化到本地（AsyncStorage 键名与 Web localStorage 的
  `starcloud.*` 系列一一对应，见 docs/reader-interaction.md 第六节）

### F5 翻页模式

与 Web 端一致（消费 @starcloud/shared，见 docs/reader-interaction.md），
阅读器内二选一：

1. **点击翻页（tap）**
   - 屏幕左右两半分区，含义随「翻页方向」偏好镜像
     （shared.tapZoneAction，与 Web 相同的判定）
   - 翻页方向设置：「向左下一页」（默认）/「向右下一页」
2. **滑动翻页（swipe）**
   - 轴向二选一：左右滑动 / 上下滑动
   - 左右滑动：横滑手势判定 |dx|>50 且 (dx>0)===(方向为 left-next)
     即下一页（公式与 Web EpubViewer 逐字一致）；此模式下同样显示
     「翻页方向」子选项（与 tap 语义相同）
   - 上下滑动：无缝滚动，滚到底自动接下一章（TXT 为 ScrollView
     连续滚动，EPUB 为 flow=scrolled + manager=continuous 连续渲染，
     与 Web 映射表一致）
   - 上下滑动无任何子选项（单页翻动样式已从交互规格删除，见
     docs/reader-interaction.md 第八节，不得再实现）

### F6 性能要求

- 大文件（TXT 数 MB、EPUB 含大量章节）不得整本载入内存渲染：
  TXT 分块按需读取，EPUB 由 epubjs 按章节惰性加载。
- 书架列表使用虚拟化列表（FlatList），千本级书库不掉帧。
- 阅读进度防抖上报（3s，章节/页变化才报），与 Web 端策略一致。

### F7 云端书籍下载（手动）

- 书架中每本云端书提供明确的「下载」按钮，
  点击后才将文件下载到 App 私有目录并转为本地书。
- **不做任何自动下载**；已下载条目显示标记，点开即读本地副本。
- 下载的书保留云端书籍 ID：阅读进度双写（本地 + 服务器）。

### F8 离线能力

- EPUB 渲染引擎（epubjs + jszip）随安装包分发，无 CDN 依赖；
  本地 EPUB 完全离线可读。
- TXT 本地书完全离线可读。
- PDF 在线阅读依赖网络直载文件；离线 PDF 支持暂未完成。

## 非目标（本期不做）

- iOS 分发（技术上可行，需要 Apple 开发者账号，暂缓）
- 云端书籍自动下载 / 自动缓存
- 书籍格式转换、TTS、笔记批注

## 分发形态

采用**单包双形态**：一个 APK 同时覆盖两类用户。

- 未配置服务器的用户获得完整的纯本地阅读体验，
  运行时不产生任何网络请求（云端逻辑仅在已配置时可达）；
- 配置了服务器的用户额外获得云端书架、下载与进度同步。

不拆分「纯阅读器」与「完整版」两个安装包：
避免双分支维护成本，且完整版对纯本地用户无实际损害。
未来若需上架「完全离线」极简版，云端逻辑集中于
src/api/client.ts 单点，可在构建期以环境变量开关物理剔除。
