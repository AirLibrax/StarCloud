# 安卓 App（apps/mobile）功能规格

> 状态：暂未完成。本文档为开工前的需求冻结稿，
> 实现时以此为准，有变更先改文档再改代码。

## 技术栈

- Expo + React Native + TypeScript
- EPUB 渲染：WebView 内嵌 epubjs（与 Web 阅读端同一套渲染与进度逻辑）

## 功能需求

### F1 双书源

- **云端书源**：登录服务器后读取书架，下载/在线阅读，进度同步到服务器。
- **本地书源**：通过系统文件选择器导入设备上的 EPUB / PDF / TXT，
  导入的书籍元数据与阅读进度保存在本地（SQLite / AsyncStorage）。
- 无服务器配置时 App 完整可用（纯本地模式）；
  配置服务器后出现「我的书架」，本地书与云端书并列展示。

### F2 权限最小化

- App 运行期间**不申请任何存储权限**。
- 导入图书使用系统文档选择器（SAF，`expo-document-picker`），
  仅获得用户所选文件的临时读取授权。
- 网络访问无需运行时权限；不申请定位、通知、通讯录等任何无关权限。

### F3 设置（仅两项）

| 设置项 | 说明 |
|--------|------|
| 服务器地址 | 如 `https://books.example.com`，留空即纯本地模式 |
| 访问令牌 | 登录成功后由服务端签发的 JWT |

- 提供「测试连接」按钮。
- 其余偏好（字号、行距等排版设置）属于阅读器内设置，
  存放于本地，不占用本设置页。

### F4 阅读器排版

与 Web 阅读端一致：

- 字号：8 档（80% – 180%）
- 行间距：4 档（1.4 / 1.6 / 1.9 / 2.2 倍）
- 左右页边距：4 档（窄 / 中 / 宽 / 很宽）
- 单列 / 双列二选一
- 所有设置持久化到本地

### F5 翻页模式

阅读器内二选一：

1. **分页式**
   - 翻页轴向可选：左右翻页 / 上下翻页
   - 左右翻页时提供方向反转设置：
     「向左滑 = 下一页」（默认）或「向右滑 = 下一页」（适配部分用户习惯）
   - 点击屏幕边缘区域也可翻页（左 1/3 上一页，右 1/3 下一页）
2. **滚动式**
   - 上下无缝拖动，无分页边界，类似长网页连续阅读
   - 按滚动位置换算阅读进度

### F6 性能要求

- 大文件（TXT 数 MB、EPUB 含大量章节）不得整本载入内存渲染：
  TXT 分块按需读取，EPUB 由 epubjs 按章节惰性加载。
- 书架列表使用虚拟化列表（FlatList），千本级书库不掉帧。
- 阅读进度防抖上报（约 1.5s），与 Web 端策略一致。
